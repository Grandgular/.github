# .github

This is a special GitHub repository that contains the organization profile README displayed on the [Grandgular GitHub organization page](https://github.com/Grandgular).

## Structure

```
.github/
├── profile/
│   └── README.md    # Organization profile README (displayed on github.com/Grandgular)
└── README.md        # This file
```

## About

The `profile/README.md` file is automatically displayed on the Grandgular organization page when users visit https://github.com/Grandgular

For more information about organization profile READMEs, see [GitHub's documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

## Making Changes

To update the organization profile:

1. Edit `profile/README.md`
2. Commit and push your changes
3. The changes will appear on the organization page within a few moments
